# DeepLearning-NIDS

This repository contains the core deep learning implementations, models, and experimental notebook architectures developed during my research on high-performance Network Intrusion Detection Systems (NIDS).

## Key Research Features
* Multi-Architecture Evaluation: Implementations exploring recurrent structures including Simple RNN, Long Short-Term Memory (LSTM), and Gated Recurrent Units (GRU) for structural comparison.
* Binary & Multi-Class Classification: Notebooks tailored to handle both binary threat detection and complex multi-class network attack classification.
* Data Pipelines: End-to-end data preprocessing pipelines optimized for parsing flow-based and packet-based network representations using standard datasets (such as CICIDS2017 and NSL-KDD).

## Tech Stack
* Languages: Python
* Frameworks & Libraries: TensorFlow, Keras, Pandas, NumPy, Scikit-Learn
* Development Environments: Jupyter Notebook

## Academic Application
This empirical codebase supports my published peer-reviewed journal papers investigating the optimization of neural network topologies for reliable anomaly detection in sensitive environments. The architectures focus on minimizing training overhead while maintaining high classification accuracy and resilient model performance against complex patterns.
